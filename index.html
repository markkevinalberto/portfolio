01 · Headless website

jcsgo.org

An Astro frontend pulling content from a WordPress backend at cms.jcsgo.org over the REST API, so staff edit pages in WordPress while the public site stays fast and static.

Deploys itself: a GitHub Actions workflow builds on push and ships to Hostinger through a self-hosted runner.

Astro WordPress REST API GitHub Actions Hostinger

02 · Booking platform

jcsgo-room-booking

A Next.js 16 app for reserving any of JCSGO's 40 rooms across 5 buildings. The interesting part isn't the calendar UI, it's that two people can never book the same room at the same time, because the database won't let them.

03 · Public booking site

JCSGO SEED DOME

The public face of the booking platform: an indoor basketball court, rented out by the hour with real-time availability shown up front so nobody calls to ask if a slot is free.

Rates start at PHP 2,000/hour, paid via GCash, no back-and-forth required to lock in a time.
