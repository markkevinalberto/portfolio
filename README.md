# Portfolio

Mark Kevin Alberto's portfolio, live at [markkevinalberto.github.io/portfolio](https://markkevinalberto.github.io/portfolio/).

Built with Vite, React, Tailwind CSS, and GSAP. Deploys automatically to GitHub Pages on every push to `main` via `.github/workflows/deploy.yml`.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
